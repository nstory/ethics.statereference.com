{%- comment -%} The category filter. The boxes live outside the form and carry no `name`, so they're JS-only: search.js turns them into ?category= and fills in each count from the index. Each box's value is the URL slug; data-category is the exact Pagefind filter value, the category name from _data/categories.yml. From md up it's a plain sidebar. Below that, offcanvas-md turns the same markup into a drawer, opened by the Categories button beside the sort control, so a phone shows results first rather than a list to scroll past. The drawer's header, title and close button only exist below md; at md and up Bootstrap hides the header and the legend is the heading instead. {%- endcomment -%}
