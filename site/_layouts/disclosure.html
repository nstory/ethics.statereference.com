{%- comment -%} Everything Pagefind indexes for this disclosure. The page itself shows the PDF, so this is hidden: `hidden` keeps it out of the rendered page and out of the accessibility tree, but leaves it in the HTML, which is all Pagefind reads. data-pagefind-body narrows indexing to this element -- note that it also drops every page without the attribute from the index. The empty span carries the fields the search results display; they're in attributes rather than inline (`key:value`) because only one inline value is allowed per element, and it has to come last. The sort key is the filing date. Most are a full ISO date but about one in twelve is a bare year, and Pagefind compares a sort key as text unless every value is numeric -- so the short ones sort to the edge of their year rather than out of it, which is as good as the date we have. {%- endcomment -%}
