{%- comment -%} The search box itself, shared by the navbar and /search/. assets/js/search.js binds to the one instance on the page, so only ever render it once. Pass categories=true to append the category filter, an input-group dropdown of checkboxes. It's JS-only: the boxes carry no `name`, so a no-JS GET submits the query alone, which is all /search/ could act on without JS anyway. The submit button is the exception -- it works with or without JS, and it has to come last in the group so the filter isn't the control that looks like the action. {%- endcomment -%}
